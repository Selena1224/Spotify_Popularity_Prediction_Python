Can audio data predict the next hit?

A large-scale analysis of 176,773 Spotify tracks combining regression, classification, and clustering to turn audio characteristics into practical marketing decisions.

Explore the analysis View GitHub Repository
01 · Business problem

Millions of tracks. Limited promotional attention.

Record labels, streaming platforms, playlist curators, and artists must decide where to invest promotion. The challenge is that commercial success depends on more than sound alone. This project tests what audio features can explain, which tracks appear promising, and how songs can be segmented for targeted campaigns.

Three decisions, one analytical pipeline

Predict an exact popularity score, classify whether a track is likely to be a hit, and identify distinct sonic segments that can support tailored playlist and campaign strategies.

06 · Notebook deep dive

From raw CSV to marketing recommendations.

This section follows the actual Python notebook step by step. Each code block shows what was implemented, why it was needed, and how the output informed the next analytical decision.

01

Load and audit the raw dataset

The workflow began by loading the Kaggle CSV into a pandas DataFrame and checking its shape, column names, missing values, and first rows. This established the dataset structure before any transformations were made.

Remove incomplete and duplicated tracks

The single incomplete record was removed, followed by duplicate songs identified through track_id. This reduced the data from 232,725 records to 176,773 unique tracks.

04

Encode categorical audio metadata

Scikit-learn models require numeric inputs. The notebook converted musical key, mode, and time signature into encoded columns before building the regression feature matrix.

le_key = LabelEncoder()
le_mode = LabelEncoder()
le_time = LabelEncoder()

df["key_encoded"] = le_key.fit_transform(df["key"])
df["mode_encoded"] = le_mode.fit_transform(df["mode"])
df["time_encoded"] = le_time.fit_transform(
    df["time_signature"]
)
Why it mattered: This allowed categorical musical characteristics to be included alongside continuous audio measurements in the same model.

Create a marketing-friendly hit classification target

The notebook converted popularity into a binary decision variable. A track scoring 50 or higher was labeled a hit. This produced 40,703 hits, representing 23% of the cleaned dataset.

07

Scale features and compensate for class imbalance

Because the predictors used very different units, the notebook standardized them with StandardScaler. The classifier also used balanced class weights so the smaller hit class would not be ignored.

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

model_log = LogisticRegression(
    max_iter=1000,
    random_state=42,
    class_weight="balanced"
)

model_log.fit(X_train, y_train)
Why it mattered: Without scaling, large-unit variables such as duration could dominate optimization. Without class weighting, predicting mostly non-hits could appear accurate while failing the actual marketing objective.

09

Choose clustering features and determine K

For segmentation, the notebook selected eight attributes that describe a track's sonic identity. These variables were standardized before testing cluster counts from 2 through 10 with the elbow method.

cluster_features = [
    "danceability", "energy",
    "acousticness", "instrumentalness",
    "valence", "tempo",
    "loudness", "speechiness"
]

X_scaled = StandardScaler().fit_transform(
    df[cluster_features]
)

for k in range(2, 11):
    km = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )
    km.fit(X_scaled)
    inertia.append(km.inertia_)
Why it mattered: The elbow method provided a structured way to balance compact clusters against unnecessary complexity.
10

Train the final K-Means model and visualize it with PCA

The final model used five clusters. PCA reduced the standardized eight-dimensional feature space to two dimensions for visualization, while grouped means were used to profile and name each segment.

km_final = KMeans(
    n_clusters=5,
    random_state=42,
    n_init=10
)

df["cluster"] = km_final.fit_predict(X_scaled)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

cluster_profile = (
    df.groupby("cluster")
      [cluster_features + ["popularity"]]
      .mean()
      .round(2)
)
Business translation: The clusters became actionable audience and playlist segments rather than remaining abstract mathematical groups.
07 · Implementation choices

Why these methods were selected.

Linear Regression

Interpretability first

Provides a transparent baseline and coefficients that directly show the direction of each feature's relationship with popularity.

Logistic Regression

Actionable screening

Transforms a continuous outcome into a practical marketing decision while preserving interpretable feature effects.

K-Means

Unsupervised segmentation

Discovers natural audio profiles without requiring predefined audience labels.

PCA

Readable visualization

Compresses eight standardized features into two plotting dimensions so cluster separation can be inspected visually.

08 · Recommendations

Use the models as a screening system, not a crystal ball.

01

Prioritize dance and electronic segments

Use Feel-Good Dance and High-Energy Electronic tracks as primary campaign targets because they produced the highest average popularity.

02

Use logistic regression for early filtering

Its 75% recall makes it better suited to surfacing promising candidates than issuing final go or no-go release decisions.

03

Add non-audio signals

Artist reach, playlist exposure, release date, chart history, marketing spend, and social virality could explain much of the missing variance.

04

Build genre-specific models

A single relationship may not apply equally to pop, classical, electronic, and spoken-word tracks. Genre-stratified modeling would improve relevance.
